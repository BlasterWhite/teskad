# docs/native

These documents are the development notes of the native rewrite. They date from before the
app was renamed Teskad and are kept as they were, for developers: in them, « Hangar » (and
`hangar-*` crate names, `.hangar/`, `hangar-kit.json`, `hangar/<task>` branches) names the app
as it was called then. Read it as Teskad. For the app as it is now, see the
[README](../../README.md), [docs/guide](../guide/) and [CHANGELOG](../../CHANGELOG.md).
